# Enterprise Network Design & Simulation

## Overview
Multi-department enterprise network built in Cisco Packet Tracer 
featuring VLAN segmentation, inter-VLAN routing, DHCP, and OSPF 
dynamic routing.

## Technologies Used
- Cisco Packet Tracer
- VLANs (VLAN 10 - IT, VLAN 20 - HR)
- Inter-VLAN routing (Router on a stick)
- OSPF dynamic routing
- DHCP
- Trunk and access ports
